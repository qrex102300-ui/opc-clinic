## Acquisition execution

### AllWebList — attempted, explicitly blocked, not counted

A fresh zero-cost directory screen found AllWebList's public submission form requires only website title, URL, description, category, and an objective content-policy checkbox; it does not request a person name, email, account, payment, or private credential. The one-shot public-facts-only workflow therefore attempted a submission without bypassing any security control.

The live response explicitly displayed **`Submission Blocked`** and **`An error occurred while submitting your website. Please try again.`** The page also contains generic success text in static markup, so the first machine classification was corrected rather than inflating the scorecard. This surface is **not** counted as submitted, pending, or confirmed. Sanitized evidence: [`allweblist-submission.md`](./allweblist-submission.md).

### LaunchFree — high-fit surface, but identity-gated

Fresh public evidence shows LaunchFree is a free product-launch directory aimed at bootstrap founders and reports permanent listings, a dofollow backlink, weekly newsletter exposure, no account requirement, and manual review. Its actual live submission form nevertheless requires **Your Name**, **Email**, **Short Bio**, a discovery-source field, and acceptance of its Terms/Privacy Policy. Because the sprint does not invent identity or use private contact credentials, no submission was made.

This is a screened acquisition opportunity, not a lead and not a listing. It should only be pursued if an authorized public founder/contact identity is intentionally supplied outside this automation.
