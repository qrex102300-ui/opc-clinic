## Acquisition execution and screening

The run prioritized fresh, zero-cost external discovery routes that could be used without owner identity, private credentials, payment, reciprocal funnel changes, or unsolicited promotional comments.

### NoSignupTools — identity optional, but product-fit constraint blocks submission

- Surface: https://nosignuptools.com/submit
- The live submission form makes submitter name and email optional and charges no fee.
- However, the directory explicitly accepts tools whose usable core requires **no signup or personal information**. OPC Clinic's free public prompt is accessible without signup, but the promised free bottleneck triage is delivered through GitHub Issues, which requires a GitHub account to submit.
- Decision: **not submitted**. The fit is ambiguous enough that forcing a listing would risk violating the directory's stated curation rule.

### Startup Buffer — business-email gated

- Surface: https://startupbuffer.com/site/submit
- Startup submission is free and does not require an account, but the live form requires a **Business Email** before continuing.
- Decision: **not submitted**. No private/contact identity was supplied.

### Verified Tools — free queue, but asset-heavy and not a low-friction identity-free win

- Surface: https://www.verifiedtools.info/submit
- Free submissions exist, but the current queue is advertised at roughly 7–9 weeks and the form requires a logo plus 1–3 screenshots.
- Decision: **not submitted in this sprint run**. This is too slow for the 7-day revenue objective and materially lower priority than routes that can create near-term qualified reach.

### AgentMRR — high-fit agent marketplace, but authenticated writes require a private agent key

- Surface: https://agentmrr.ai/ and https://agentmrr.ai/docs
- The marketplace is highly relevant to agent-built tools and exposes a public proof-of-work registration flow.
- Product submission requires an `Authorization: Bearer ...` API key returned after agent registration.
- Decision: **not registered or submitted** because the sprint operating rule prohibits use of private credentials. No key was generated or stored.

### Reciprocal-link / account routes remain rejected

Fresh checks also reinforced the existing stop rule for routes such as JustTools, Launchpadly, Dofollow.Tools, First Look, and DeepLaunch: their free paths require sign-in and/or a backlink/badge on the product site. Those are not acquisition wins worth changing the funnel for without user-behavior evidence.
